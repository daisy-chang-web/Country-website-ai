# Taiwan Country Website

A four-page, mobile-first travel guide about Taiwan built with semantic HTML, CSS and a small JavaScript navigation menu.

## Pages

- `index.html` - home and overview
- `attractions.html` - places to visit
- `food.html` - Taiwanese food, table and contact form
- `credits.html` - media and resource attribution

## Run locally

Open `index.html` in a browser or serve the folder with a static server.
